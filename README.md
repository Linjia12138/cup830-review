# 830 化工原理 · 考点与题库

面向中国石油大学（北京）830《化工原理》，适用2026年12月初试（2027年招生）。

**网站：https://linjia12138.github.io/cup830-review/**

点击知识点可以查看出现年份、对应题目及原PDF扫描页。题库支持关键词、年份、题型、模块和考点筛选；收藏与个人笔记保存在当前浏览器。

## 数据范围

- 1999—2010、2021—2025共17个年份，373道原编号题，其中1道知识点未判定；34个知识点。
- 近五年为2021—2025：120道题、24道计算题。
- 2011—2020的汇编自述为依据回忆考点整理的类似模拟题，不进入主统计。
- 2010、2021为回忆版，其他资料为题卷汇编，未独立核实为官方原卷。
- 年频次按出现年份去重；题数按原编号题计；多个知识点可对应同一道题，不能把各考点题数相加。
- 扫描页为原PDF查看器页码，保留公式与图示。识别文字仅作检索辅助，未补造答案。
- 当前缺少2026招生年份题卷。汇编的“2026最新版”不是该年份原卷。
- 2027招生大纲来源：[学院2026-09-28公告](https://www.cup.edu.cn/chem/yjsjy/zsxx/5a902f3edc204a848af26709529a55af.htm)。

## 使用与部署

无外部依赖的静态网站。直接打开`index.html`，或通过静态HTTP服务器访问。GitHub Pages从`main`分支根目录部署，路由使用URL片段，题目和筛选结果可直接分享。

`assets/data.js`包含整理后的题目、考点、资料覆盖与复习重点；`assets/pages/`包含主统计年份的原题扫描页；`downloads/`包含Excel统计和Markdown解读。

数据构建脚本：

```text
python -X utf8 tools/build_data.py --source /path/to/reviewed-analysis --originals /path/to/original-materials
```

输入须包含人工核对后的`考频数据.json`、`模块概要.json`及原PDF。需PyMuPDF和Pillow，可用`--deps`指定本地依赖目录。脚本只生成输出文件，不改原始资料。

## 已知限制

历史汇编、回忆资料有残缺、分值缺口与版本数值差异。网站逐年保留这些说明，不以错误合计推算分值占比。考频反映现有资料，不是下一次命题概率。收藏和笔记不跨设备同步，可在收藏页导出与导入备份。

本站分析与界面为整理成果；扫描资料保留来源标识，相关原题与出版材料的权利归各自权利人。
